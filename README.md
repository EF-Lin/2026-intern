# 2026 INTREN
A project aim to process DAS (Distributed Acoustic Sensing, 分散式光纖聲學感測) data. Specially designed for MiDAS data.

## Features
- Read MiniSEED data
- Wave and waterfall plot focus on certain peroid

## Installation
### pip
```bash
pip install -e .
```

### uv
```bash
uv sync
```
